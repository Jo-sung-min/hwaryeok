# 급상승 제품 랭킹

## 목적

화력에 직접 작성된 사용자 리뷰가 최근 늘어난 제품을 발견하는 공개 랭킹이다. 판매량, 외부 쇼핑몰 순위, 조회수, 관리자 점수나 개인화 적합도를 급상승으로 표현하지 않는다.

## 집계 기준

- 조회 시각을 기준으로 최근 7일과 직전 7일을 비교한다. UTC 기준으로 정확히 7 × 24시간씩 계산한다.
- 최근 구간은 `[recentStart, asOf)`, 이전 구간은 `[previousStart, recentStart)`다. 경계 시각의 리뷰는 두 구간에 중복 집계하지 않고, 미래 시각의 리뷰는 제외한다.
- `reviewGrowth = recentReviewCount - previousReviewCount`다. 증가량이 1 이상인 제품만 노출한다.
- 공개 상태(`PUBLISHED`)인 제품에 활동 중인 계정(`ACTIVE`)이 직접 작성한 리뷰만 집계한다. 계정이나 제품 공개 상태가 바뀌면 이후 조회 집계에서 제외된다.
- 정렬은 **리뷰 증가량 내림차순 → 최근 리뷰 수 내림차순 → 최근 평균 리뷰점수 내림차순 → 제품 ID 오름차순**이다.
- 평균 리뷰점수는 사용자가 제품에 매긴 100점 척도의 점수다. 다른 사용자가 리뷰에 매기는 ‘리뷰 화력’과는 다른 값이다.
- 순위는 선택한 카테고리 안에서 매긴다. 카테고리 필터를 먼저 적용한 다음 페이지를 나눈다.
- 충분한 리뷰 증가가 없으면 빈 목록을 반환한다. 높은 관리자 점수나 임의 상품으로 빈 순위를 채우지 않는다.

## 공개 API

`GET /api/v1/rankings/rising?category=앰플&page=0&size=12`

인증 없이 조회할 수 있다. `page`는 0 이상의 정수, `size`는 1~50이며 기본값은 각각 0과 12다.

응답 필드:

| 필드 | 의미 |
| --- | --- |
| `category` | 선택 카테고리. 전체는 `null` |
| `content[].product` | 기존 공개 제품 응답. 이 안의 일반 성분 점수는 급상승 점수가 아님 |
| `content[].rank` | 선택 카테고리의 급상승 순위 |
| `content[].reviewCount` | 기준 시각 이전의 전체 공개 사용자 리뷰 수 |
| `content[].recentReviewCount` | 최근 7일의 공개 사용자 리뷰 수 |
| `content[].previousReviewCount` | 직전 7일의 공개 사용자 리뷰 수 |
| `content[].reviewGrowth` | 두 구간의 리뷰 수 차이 |
| `content[].recentReviewScore` | 최근 7일 제품 리뷰 평균 점수, 소수점 첫째 자리 |
| `page`, `size`, `totalElements`, `totalPages`, `hasNext` | 카테고리 필터를 적용한 페이지 정보 |
| `categories[].name`, `categories[].productCount` | **카테고리 필터 전** 급상승 조건을 충족한 제품의 카테고리별 개수 |
| `window.asOf`, `window.recentStart`, `window.previousStart`, `window.days` | 실제 사용한 UTC 집계 구간과 일수 |
| `scoreBasis` | 화면에서 표시할 수 있는 집계 기준 설명 |

카테고리 별칭은 기존 랭킹과 동일하게 `선크림 → 선케어`, `클렌징폼 → 클렌저`로 통합한다. 빈 값, `전체`, `전체보기`, `전체상품`은 전체 상품을 뜻한다.

## 구현 및 검증

집계·정렬·페이지 제한은 데이터베이스에서 처리한다. 일반 제품 성분 분석은 반환할 페이지의 제품에만 수행한다. 한 요청의 카테고리 수, 순위 및 상품 데이터가 같은 공개 상태를 보도록 읽기 전용 반복 읽기 트랜잭션을 사용한다.

테스트는 별도의 H2 테스트 데이터베이스에서 실행하며 실제 서비스 계정이나 제품에 시험 리뷰를 넣지 않는다. 검증 범위는 빈 집계, 정확한 날짜 경계, 미래 리뷰 제외, 상승·정체·하락 구분, 정렬 동점 처리, 활동/공개 상태, 카테고리 별칭, 페이지 제한 및 비로그인 API 접근이다.
