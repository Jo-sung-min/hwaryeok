# 화력 메인 UI · 개인맞춤 아이덴티티 개편

## 방향

**화장품의 기준을, 내 피부로.**

화력의 개인맞춤은 장식 문구가 아니라 사용자가 저장한 피부 조건에 따라 상품 순서와 추천 이유가 달라지는 경험이다. 홈에서 설정 진입, 현재 적용 상태, 결과 확인이 이어지도록 한다. 실제 리뷰와 개인맞춤 지표는 혼합하지 않는다.

## 메인 구성

1. 짧은 브랜드 메시지와 제품 검색
2. 성분·제품 이미지 배너: PC 3개, 태블릿 2개, 모바일 1개, 최대 10개 순환
3. 내 피부 설정 패널: 시작 버튼 또는 실제 저장된 조건과 설정 수정
4. 전체 상품 / 나의 맞춤 상품: 카테고리 필터, 현재 정렬 기준, 전체보기
5. 내 피부에 맞는 제품 랭킹: 맞춤 화력 + 추천 이유
6. 급상승 랭킹: 실제 리뷰 증가량 기준
7. 별도 광고 안내와 접이식 점수 설명

## 상태별 경험

| 상태 | 설정 패널 | 상품 진열 | 다음 행동 |
| --- | --- | --- | --- |
| 비로그인 | 가입 없이 체크 가능 안내 | 전체 상품 · 제품명순 | 나의 성분 찾기 → 결과 체험 → 로그인 후 확인·저장 |
| 로그인 · 미설정 | 저장된 피부 설정 없음 안내 | 전체 상품 · 제품명순 | 피부 체크 후 결과 저장 |
| 로그인 · 설정 완료 | 피부 타입·수분·유분·민감도 중 실제 저장된 값만 표시 | 맞춤 화력 높은 순 | 맞춤 랭킹 확인 또는 저장된 피부 설정 수정 |

설정이 없을 때 가상의 피부 타입이나 개인화 점수를 표시하지 않는다. 비회원 피부 체크 체험을 했더라도 저장 전에는 메인이 개인화된 것처럼 표시하지 않는다. 피부 설정은 공개 주소의 검색 조건에 노출하지 않는다.

## 화면 원칙과 적용

- 흰색 배경, 연분홍 선택·맞춤 영역, 진한 중립색 본문. 그라데이션은 사용하지 않는다.
- 큰 제목, 제품명, 가격, 개인 점수, 추천 이유를 각각 구분한다. 분홍색을 모든 본문에 사용하지 않는다.
- 공통 헤더·버튼·입력·카드의 과한 그림자와 이동 효과를 제거한다.
- 상단의 ‘내 피부 맞춤’, ‘내 피부 랭킹’과 모바일 중앙 ‘내 피부’로 핵심 진입을 유지한다.
- 카테고리의 ‘전체’와 다른 페이지로 이동하는 ‘전체보기’를 구분한다.
- 상품 카드는 PC 4열, 모바일 기본 진열 2열. 랭킹은 모바일에서 가로 탐색한다.
- 개인화 상품에는 실제 응답의 추천 이유를 표시하며, 근거 수준이 낮은 경우 추가 확인 안내를 붙인다.
- 맞춤 화력, 사용자 리뷰, 광고 점수는 별개다. 개인별 효과를 보장하는 표현을 쓰지 않는다.
- 키보드 초점, 자동 배너 일시정지, 작은 화면 넘침을 점검한다.

## 이번 범위

메인과 공통 화면 스타일, 개인 설정 요약, 상품 카드, 맞춤 랭킹의 용어·설정 이동을 수정했다. 기존 추천 계산식·리뷰 집계·저장 API는 유지한다. 모든 내부 페이지를 별도 디자인으로 전면 재제작하거나 새로운 피부 진단 기능을 추가한 것은 아니다.

## 확인 항목

- 기존 홈 분기·배너 테스트 4개, 새 설정 표시 테스트 4개
- 실제 서버 컴포넌트 렌더링 테스트: 설정 유무와 개인 점수·추천 이유 표시
- 전체 프런트엔드 빌드와 타입 검사
- PC/모바일 홈, 카테고리 이동, 피부 체크 진입, 모바일 검색과 가로 넘침

로그인 상태별 표시는 격리된 가상 입력으로 검증하며 실제 사용자 계정이나 리뷰 데이터는 만들지 않는다.

### 검증 결과 (2026-09-07)

- 홈·피부 설정 helper 8개 + 실제 컴포넌트 서버 렌더링 10개, 총 18개 테스트 통과
- 전체 36개 경로 프런트엔드 빌드 및 타입 검사 통과
- PC 3개 배너, 모바일 1개 배너와 상품 2열 진열 확인
- 앰플 선택 시 실제 3개 상품 표시, 모바일 ‘토리든’ 검색 시 2개 결과 확인
- 피부 체크 페이지 진입 확인, 390px·320px 화면에서 문서 가로 넘침 없음
- 작업 중 스타일 파일 교체 시 개발 모드가 잠시 재컴파일했으며 최종 빌드와 페이지 표시 정상
