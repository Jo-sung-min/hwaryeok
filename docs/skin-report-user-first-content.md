# 피부 리포트·맞춤 랭킹 문구 개편

## 적용 방향

결과 화면은 ‘내 피부에 무엇이 잘 맞을까?’에 먼저 답한다. 면책·집계 방식·점수 정의를 큰 박스로 반복하지 않는다. 긴 설명은 기존 `/principles#skin-guide` 안내에 모으고 화면에는 작은 링크로 연결한다. 자가 체크라는 표시, 꼭 필요한 새 제품 사용 주의, 데이터가 없다는 사실은 숨기지 않는다. 사진 외부 전송 동의처럼 실행 전에 필요한 개인정보 안내는 이동 대상이 아니다.

## 변경

- 피부 결과 상단: 추천 보습 성분 2개와 선택 이유, 제형, 부위별 사용법, 민감·트러블 관련 제품 표시.
- 성분 카드: 실제 성분 사전 검색으로 연결. 특정 상품의 확인되지 않은 성분·효능을 만들어내지 않음.
- 세부 리포트: ‘측정이 아님’, ‘판단에 사용하지 않음’ 등의 반복 문구를 줄이고 세안·보습·루틴 선택 팁으로 구성.
- 맞춤 랭킹: 면책 박스 대신 같은 공통 규칙으로 생성한 성분·제형 가이드. 점수·정렬·제품 데이터 자체는 변경하지 않음.
- 유형 통계: 회원 비율과 분모·집계일은 표시하고 세부 집계 조건은 안내 페이지로 이동. 작은 표본·조회 실패에서는 비율을 만들지 않음.
- 추천 기준 안내: 코드 의미, 의료 진단과의 차이, 점수/리뷰 구분, 추천 한계, 통계 모집단/최소 인원, 참고 출처 통합.

## 추천 표현의 근거

히알루론산·세라마이드와 보습 제형에 관한 일반 정보는 [미국피부과학회 보습제 선택 안내](https://www.aad.org/public/everyday-care/skin-care-basics/dry/pick-moisturizer)를, 지성 피부의 가벼운 보습 및 제품 표시 선택은 [지성 피부 관리 안내](https://www.aad.org/public/everyday-care/skin-care-basics/dry/oily-skin)를 참고했다. 답변별 문구 분기는 화력의 화장품 선택 가이드이며 임상적으로 검증된 개인별 처방이 아니다. 확정적인 적합성·치료·효능 보장 표현은 사용하지 않는다.

## 확인 항목

등록 프로필과 비회원 체크에서 공통 가이드 사용, 건성/지성/수부지/복합성/민감 반응 분기, 역방향 복합성(볼이 더 번들거림), 실제 통계 분모 유지, 안내 링크, 결과 읽기 전용 및 기존 답변 수정 보존.

검증: 프론트엔드 타입 검사·배포용 빌드 통과. 전체 테스트 42개 통과. 이번 변경은 화면 문구와 추천 가이드에 한정하며 피부 유형 계산, 상품 점수, 저장된 답변은 변경하지 않았다.
