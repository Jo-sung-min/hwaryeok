# 고민별 화장품 검색 기획 및 적용 결과

## 목표

제품명을 모르는 사용자도 `주름`, `모공`, `트러블`처럼 현재 고민만 검색하면 관련 성분이 실제로 연결된 제품을 찾을 수 있게 한다.

## 검색 원칙

1. 검색어에서 피부 고민 단어와 남은 제품 검색어를 분리한다.
   - `주름` → `탄력·잔주름`
   - `주름 크림` → `탄력·잔주름` + 제품 유형 `크림`
   - `미백 세럼` → `잡티·칙칙함` + 제품 유형 `세럼`
2. 고민은 기존 `ingredient_concern_features`와 `ingredient_tags`를 통해 제품의 전성분 연결 관계와 대조한다.
3. 검색 결과는 기존 화력 점수, 개인 피부 설정, 성분 근거 신뢰도를 함께 반영해 정렬한다.
4. 검색어와 무관한 인기 제품으로 빈 결과를 채우지 않는다.
5. 함량이 공개된 성분은 데이터 신뢰도에 반영하되, 함량이 높을수록 무조건 좋은 제품으로 계산하지 않는다.

## 고민 사전

| 사용자 표현 | 내부 고민 | 대표적으로 살펴볼 성분 |
| --- | --- | --- |
| 보습, 수분, 건조, 당김 | 속건조·당김 | 히알루론산, 판테놀, 세라마이드 |
| 유분, 피지, 번들거림 | 유분·번들거림 | 나이아신아마이드, 징크 PCA, 살리실산 |
| 트러블, 여드름, 뾰루지 | 트러블·여드름 | 어성초, 판테놀, 아젤라익애씨드 |
| 모공, 블랙헤드 | 블랙헤드·모공 | 살리실산, 나이아신아마이드, 징크 PCA |
| 민감, 홍조, 붉은기, 진정 | 붉은기·민감 | 판테놀, 어성초, 비사보롤 |
| 장벽, 각질, 피부결 | 장벽·각질 | 세라마이드, 판테놀, 우레아 |
| 미백, 잡티, 기미, 칙칙함 | 잡티·칙칙함 | 나이아신아마이드, 트라넥사믹애씨드, 비타민 C |
| 주름, 잔주름, 탄력, 안티에이징 | 탄력·잔주름 | 레티놀, 나이아신아마이드, 히알루론산 |

## 주름 검색 데이터 적용

- 레티놀의 탄력·잔주름 연결은 기존 성분사전 자료를 유지한다.
- 현재 공개 제품에 연결된 성분 중 나이아신아마이드와 히알루론산을 잔주름 외관 관리 후보로 보강했다.
- 나이아신아마이드는 5% 제형의 무작위·이중맹검·분할 얼굴 연구에서 잔주름 외관 개선이 관찰됐다. 제품별 실제 함량과 배합은 별도로 확인해야 한다.
- 히알루론산은 보습 성분으로, 국소 세럼 연구에서 수분과 잔주름 외관 지표 개선이 관찰됐다. 보습으로 건조할 때 도드라지는 잔주름을 관리하는 보조 성분으로 표현한다.
- 참고: [나이아신아마이드 임상 연구](https://pubmed.ncbi.nlm.nih.gov/18492135/), [국소 히알루론산 세럼 연구](https://pubmed.ncbi.nlm.nih.gov/34176098/), [레티놀 무작위 대조 연구](https://pubmed.ncbi.nlm.nih.gov/17515510/)

## 적용 화면

- 제품 검색창: 제품명·브랜드·피부 고민 통합 입력
- 제품 검색 상단: 8개 고민 빠른 선택 버튼
- 검색 결과 상단: 선택한 고민 설명과 함께 살펴볼 성분
- 제품 카드: 일반 효능 문구 대신 해당 고민과 연결된 실제 추천 이유 우선 표시
- 필터: `탄력·잔주름` 추가 및 현재 고민 해제 버튼 제공
- 모바일 하단 검색: 고민 검색 안내 문구 반영

## 데이터 확장 방향

현재 원천 성분 데이터에 비해 제품과 검수된 전성분의 연결이 적다. 관리자가 브랜드 공식 전성분과 식약처 기능성 품목 매칭을 검수할수록 고민 검색 결과와 추천 이유가 자동으로 정교해진다. 다음 단계에서는 고민 별칭과 성분별 가중치·출처를 관리자 화면에서 관리하는 테이블 구조로 확장한다.
