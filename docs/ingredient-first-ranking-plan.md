# 화력: 성분에서 시작하는 상품 랭킹

작성일: 2026-09-07

## 방향

화력의 모토는 **나에게 맞는 성분, 그 성분으로 고르는 화장품**이다. 사용자는 `히알루론산 → 앰플`처럼 익숙한 성분과 필요한 제품 종류를 고르고 곧바로 상품을 비교한다. 메인과 랭킹은 같은 탐색 구조를 사용하며, 로그인이나 피부 설문 없이 시작할 수 있다.

첫 화면은 짧은 소개, 성분 선택, 제품 종류 선택, 상품 진열 순서로 구성한다. 긴 서비스 설명과 큰 소개 배너를 상품보다 앞에 두지 않는다. 흰색 배경과 연분홍 선택 상태를 사용하고 그라데이션은 쓰지 않는다.

## 탐색 흐름

1. 메인에 들어오면 상품 이미지와 상품명·가격·점수가 바로 보인다.
2. 히알루론산, 판테놀, 나이아신아마이드, 세라마이드 등 등록된 대표 성분을 고른다. 저장한 관심 성분은 빠른 진입점으로 활용한다.
3. 앰플, 세럼, 토너, 크림 등 제품 종류를 고른다. `히알루론산 > 앰플`이라는 현재 조건과 일치 상품 수를 함께 보여준다.
4. 성분 화력순 또는 사용자 리뷰순으로 비교한다. 상품 카드를 누르면 상세 성분·실제 리뷰·구매 정보로 이동한다.

선택한 성분·제품 종류·정렬·페이지는 주소에 보존한다. 새로고침, 뒤로 가기, 링크 공유에서도 같은 목록을 확인할 수 있다. 성분을 바꾸면 페이지를 처음으로 돌리고 선택 조건을 명확히 표시한다.

메인과 별도 랭킹 페이지의 차이는 진입 맥락에만 둔다. 같은 조건을 입력했을 때 상품과 순서가 달라지지 않도록 공통 조회와 화면을 사용한다.

## 집계 원칙

| 구분 | 의미와 표시 |
| --- | --- |
| 성분 포함 조건 | 공개 제품과 실제로 저장된 제품·성분 연결이 있는 경우에만 해당 성분 목록에 포함 |
| 성분 미선택 | 기본 진열순으로 모든 공개 제품을 보여주되, 기본 점수를 성분 순위나 실제 리뷰점수로 표시하지 않음 |
| 성분 화력순 | 선택 성분에 대한 기존 화력 계산을 사용한 비교 순서. 성분 연결, 등록 순서, 성분 근거 등으로 계산 |
| 사용자 리뷰순 | 화력 사용자가 작성한 실제 제품 리뷰의 평균점수로 정렬. 리뷰 수를 함께 표시 |
| 리뷰 없는 상품 | 평균점수와 리뷰 순위를 만들지 않고 리뷰 대기로 표시. 실제 리뷰가 있는 상품 뒤에 진열 |
| 광고·화력 추천 | 관리자 평가를 사용한 별도 광고 영역. 성분 화력이나 사용자 리뷰점수에 합산하지 않음 |

성분 화력은 함량 백분율, 임상 효능, 특정 사용자의 실제 사용 결과를 뜻하지 않는다. 특히 등록된 주요 성분 수와 순서는 공식 전성분 전체를 확보했다는 뜻이 아니므로 해당 지표의 범위를 설명한다. 성분 화력과 실제 리뷰는 각각의 이름과 단위로 구분한다.

성분과 카테고리의 교집합을 만든 뒤 전체 결과의 순위를 계산하고 페이지를 나눈다. 페이지마다 순위가 1부터 다시 시작하지 않게 한다. 초안·비공개 제품과 중복 연결은 순위에 들어가지 않는다.

## 데이터 확장 방식

성분 옵션과 성분별 상품 수, 선택 가능한 카테고리는 공개 제품·성분 연결에서 집계한다. 화면에 성분별 상품 ID 목록을 따로 고정하지 않는다. 관리자가 제품을 공개하고 성분 연결을 추가하면 해당 성분과 카테고리 랭킹에 자동 반영한다.

미연결 제품은 일반 상품 탐색에서 볼 수 있다. 성분 필터에서는 상품명이나 마케팅 문구만으로 함유 여부를 추정하지 않는다. 결과가 없는 조합은 빈 결과와 함께 카테고리 전체 보기 또는 다른 성분 선택을 제공한다. 앰플이 없다는 이유로 세럼을 앰플로 바꾸어 표시하지 않는다.

공식 성분명의 변형과 파생 성분을 하나의 대표 성분으로 묶는 별칭 체계는 별도 검수 대상이다. 이번 예시에서는 웰라쥬 공식 전성분의 `하이알루로닉애씨드`와 화력의 `히알루론산 / Hyaluronic Acid`를 연결한다. 소듐하이알루로네이트의 함량을 히알루론산 자체의 함량으로 바꾸지 않는다.

## 시작 시점 실측과 보강 근거

2026-09-07 작업 시작 시 공개 API를 조회한 결과다. 원천 데이터 보유량과 실제 랭킹에 사용 가능한 제품·성분 연결량은 구분한다.

| 항목 | 작업 시작 시점 |
| --- | ---: |
| 공개 제품 | 22개 |
| 화력 성분 | 11개 |
| 성분이 연결된 공개 제품 | 6개 |
| 공개 제품·성분 연결 | 22건 |
| 성분 미연결 공개 제품 | 16개 |
| 히알루론산 연결 제품 | 4개 |
| 히알루론산과 앰플을 모두 만족한 제품 | 0개 |

현재 제품 종류는 토너 3, 세럼 3, 앰플 3, 에센스 1, 크림 4, 선케어 3, 클렌저 3, 마스크팩 1, 젤 1개다. 따라서 실제 앰플의 성분 연결을 보강해야 사용자가 제시한 예시가 작동한다.

## 완료 판정

1. 데스크톱과 모바일에서 메인에 접속하면 긴 소개를 넘기지 않고 상품 진열을 확인할 수 있다.
2. `히알루론산 → 앰플`을 선택하면 출처가 확인된 웰라쥬 앰플이 표시되고 다른 카테고리의 상품은 제외된다.
3. 판테놀·나이아신아마이드 등 다른 등록 성분에도 동일한 집계 구조가 적용된다.
4. 선택 조건과 정렬을 주소로 공유하고 새로고침해도 같은 목록이 유지된다.
5. 사용자 리뷰가 없는 제품에 실제 리뷰 평균이나 리뷰 순위가 생성되지 않는다.
6. 광고 관리자 점수가 일반 순위나 사용자 리뷰 평균에 섞이지 않는다.
7. 연결이 없는 조합은 명확한 빈 결과를 표시하며 관련 없는 상품으로 채우지 않는다.
8. 관리자에서 성분 연결 또는 공개 상태가 바뀌면 조회 대상과 집계 수가 함께 바뀐다.

## 운영상 남는 과제

이번 개편은 데이터가 늘어날 때 화면을 다시 개발하지 않아도 성분별 랭킹이 확장되는 구조를 만든다. 웰라쥬 보강 이후에도 남은 미연결 15개 제품은 근거를 확인하며 연결해야 한다. 공식 전성분 전체 적재, 성분 계열 별칭 검수, 사용자 리뷰 축적은 계속 진행할 데이터 운영 과제다.

## 구현 및 검증 결과

2026-09-07 로컬 PostgreSQL과 실행 중인 사이트에서 확인했다.

- 메인 `/`과 `/ranking`이 성분 선택 → 제품 종류 선택 → 상품 진열의 공통 화면을 사용한다.
- `/api/v1/ingredient-rankings/options`가 성분·제품 종류별 공개 제품 수를 제공한다.
- `/api/v1/ingredient-rankings`가 성분·제품 종류·정렬·페이지를 받아 같은 기준으로 집계한다.
- 공개 제품 22개, 성분 11개, 연결된 공개 제품 7개, 제품·성분 연결 24건이다. 히알루론산 포함 제품은 5개이며 앰플은 1개다.
- `히알루론산 → 앰플`에 웰라쥬 제품이 표시된다. 실제 리뷰가 없는 상태에서 리뷰점수와 리뷰 순위는 생성되지 않는다.
- 관심 성분 우선 표시, 전체 성분 검색, 빈 결과 안내, 조건을 보존하는 링크와 페이지 이동을 구현했다.
- 성분 사전·상세·주요 메뉴·푸터·추천 원칙에서 새 성분 랭킹으로 연결한다.
- 390×844 모바일 2열과 1280×900 데스크톱 4열 상품 진열을 확인했다. 성분·제품 종류 선택, 리뷰순 전환, 검색, 2페이지 이동 및 새로고침 유지를 확인했다.
- 백엔드 전체 테스트 62개와 프런트엔드 프로덕션 빌드가 통과했다. 실행 중인 백엔드 상태는 `UP`이다.
