# 피부 체크 결과 리포트

2026-09-10. `/skin-check?step=result`를 수정 도구가 아닌 읽기 중심 리포트로 변경했다.

## 구성

- 유형명 + 친근한 별칭: 복합성은 ‘부위별 균형 조율가’ 등 다섯 기본 경향별로 구분.
- 유분 분포 / 속당김 / 제품 반응 / 트러블 빈도를 조합한 화력 고유 코드. MBTI 검사·의학적 분류 코드가 아님을 명시.
- 같은 기본 피부 타입의 실제 회원 비율.
- 네 가지 성향 해석, 판단에 사용한 답변, 세안 당김·붉어짐·모공 세부 신호.
- 고민·사용감·루틴을 반영한 제품 선택 기준과 반응 성분·생활 습관 풀이.
- 해석의 한계와 참고 출처, 기존 맞춤 제품 추천.

상태 카드와 하단 중복 수정 버튼, 결과의 프로필 편집 연결을 제거했다. 결과에서 답변을 수정하는 진입점은 ‘답변 수정’ 버튼 하나뿐이다. 하단은 ‘리포트 확인 완료’로 홈에 돌아간다. 질문 응답·답변 노트의 편집 기능은 유지한다.

## 비율의 정의

`GET /api/v1/skin-check/statistics`는 저장된 피부 프로필과 회원 테이블을 집계하는 읽기 전용 공개 API다. 개인 식별자나 개별 답변은 반환하지 않는다.

- 대상: ACTIVE 상태의 USER 역할, profileVersion 2 이상 저장 프로필.
- 제외: 관리자·비활성 계정·기본값 버전 프로필·비회원 임시 체크.
- 회원당 최신 저장 프로필 1개. 기본 skinType으로 집계하며 새 4축 코드의 비율과 혼동하지 않는다.
- 분모가 30명 미만이면 COLLECTING, sampleSize=null, distribution=[]로 반환. 30명은 소표본 공개를 제한하는 제품 기준이며 통계적 대표성·정확도를 보장하는 임계값이 아니다.
- 30명 이상이면 유형별 count / sampleSize × 100, 소수 첫째 자리 표시. 표본 수와 집계 시점을 함께 안내한다.
- 전체 인구 비율이 아님을 표시한다. API 장애 시 집계 실패와 표본 부족을 구별하며 임의 비율을 만들지 않는다.

2026-09-10 실제 PostgreSQL 응답은 COLLECTING이었다. 퍼센트를 보이게 하려고 테스트 계정이나 프로필을 운영 DB에 추가하지 않았다.

## 복원과 검증

완료 답변이 있는 결과 URL은 새로고침 후 리포트로 복원하고 제품 추천은 새로 조회한다. 미완료 답변으로 결과 URL에 접근하면 답변 확인으로 이동한다. 수정한 답변을 기준으로 리포트와 추천을 다시 계산한다.

- 프런트 전체 테스트 30개 통과, 프로덕션 빌드 통과.
- 백엔드 통합 테스트: 30개 적격 프로필 중 12개 복합성=40.0%, 관리자/비활성/기본값 제외, 소표본 미공개 검증. 테스트 DB에서 실행하고 롤백.
- 실제 PostgreSQL API 재기동 및 COLLECTING 응답 확인.
- 브라우저에서 15문항 완료 → 리포트 → 답변 수정 → 건성에서 복합성으로 재계산 확인. 새로고침 후 리포트 복원 및 추천 제품 재조회 확인.
- 390×844, 320×568에서 가로 넘침 없음. 결과 화면의 수정 버튼 1개 확인.
- 해석 용어 참고: [미국피부과학회 피부 관리 안내](https://www.aad.org/public/everyday-care/skin-care-basics/care/skin-care-for-men). 이 자료는 화력의 설문·유형 코드·정확도를 검증한 자료가 아니다.
