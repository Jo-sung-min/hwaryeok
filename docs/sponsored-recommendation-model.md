# 화력 추천 광고 모델

## 목표

화력의 일반 리뷰점수는 실제 사용자가 작성한 리뷰만으로 계산한다. 광고 계약은 일반 리뷰점수와 맞춤 랭킹에 영향을 주지 않는다. 광고주는 별도의 `화력 추천` 탭에 노출될 기회를 구매하고, 탭 안의 노출 순서는 화력 관리자의 제품 평가로 결정한다.

## 초기 과금 방식

- 1단계는 주간 또는 월간 고정 기간형 광고로 운영한다.
- 광고비는 광고 탭에 참여하고 정해진 기간 동안 노출되는 비용이다.
- 더 많은 비용을 낸다고 관리자 추천점수가 올라가거나 일반 랭킹에 반영되지 않는다.
- 클릭당 과금과 구매 성과 과금은 노출·클릭 집계와 부정 클릭 방지 체계를 갖춘 뒤 확장한다.

## 노출 순서

1. 현재 날짜가 노출 기간에 포함되고 상태가 `노출`인 광고만 공개한다.
2. 사용자에게 공개된 제품만 광고 탭에 표시한다.
3. 신생 브랜드 우선 대상이 먼저 나온다.
4. 같은 그룹에서는 관리자 추천점수가 높은 제품이 먼저 나온다.
5. 같은 점수에서는 최근 검토·수정한 광고가 먼저 나온다.

## 관리자 추천점수 가이드

| 평가 항목 | 배점 | 확인 내용 |
| --- | ---: | --- |
| 성분 구성 | 30 | 핵심 성분과 조합이 제품 목적에 맞는가 |
| 제품 차별성 | 25 | 기존 제품과 구분되는 명확한 가치가 있는가 |
| 근거 완성도 | 20 | 전성분, 출처, 이미지 등 확인 자료가 충분한가 |
| 사용자 적합 | 15 | 대상 피부와 사용 맥락이 명확한가 |
| 판매처 신뢰 | 10 | 쿠팡 공식 브랜드·판매자 주소를 확인했는가 |

## 사용자 화면 원칙

- 모든 추천 광고에는 `광고` 표시를 고정한다.
- 관리자 추천점수와 사용자 리뷰점수를 서로 다른 카드로 표시한다.
- 추천 이유가 관리자 평가임을 명시한다.
- 구매 링크는 `https` 방식의 쿠팡 도메인만 허용한다.
- 광고 계약 여부는 일반 제품 목록, 사용자 리뷰점수, 맞춤 랭킹 계산에 반영하지 않는다.

## 관리자 운영 흐름

1. 상품을 먼저 등록하고 출처·이미지·성분을 검토한다.
2. 광고 관리에서 제품, 추천점수, 추천 한 줄, 구체적인 추천 이유를 입력한다.
3. 신생 브랜드 여부와 노출 시작일·종료일을 설정한다.
4. 쿠팡 공식판매처 주소를 입력한다.
5. 초안 상태로 검수한 뒤 `노출`로 변경한다.
6. 계약 중단이나 정보 재검토가 필요하면 `일시중지`로 전환한다.
