# 화력 식약처 데이터 사이트 적용 기획

작성일: 2026-09-04  
대상 데이터: 식품의약품안전처 기능성화장품 보고품목정보, 화장품 사용제한 원료정보

## 1. 기획 목표

식약처 동기화 데이터를 단순히 관리자 화면의 보유 건수로 남겨두지 않고 다음 세 가지 가치로 전환한다.

1. 제품 정보의 출처와 최신성을 사용자가 확인할 수 있게 한다.
2. 브랜드 공식 전성분과 사용제한 원료정보를 연결해 성분 확인을 돕는다.
3. 신규 제품 등록과 기존 제품 검수를 빠르게 만드는 관리자 도구로 활용한다.

화력의 최고 가치는 순수 사용자 리뷰와 리뷰점수다. 식약처 정보는 리뷰점수에 가산하거나 감점하지 않고, 제품 정보의 `확인 근거`와 `데이터 신뢰도`에만 사용한다.

### 2.1 1차 구현 현황

2026-09-04 기준으로 관리자 검수형 매칭 기능과 사용자 공개 카드까지 적용했다.

- 화력 상품별 식약처 품목 후보 검색 및 유사도 표시
- 관리자 확인 연결·교체·해제 및 `해당 없음` 검수와 검수자·검수일·검수 메모 기록
- 전체 상품의 연결·해당 없음·미검수 수량과 검수 진행률 표시
- `ADMIN_VERIFIED` 연결만 사용자 제품 상세에 공개
- 제품 상세에 품목명, 책임판매업체, 보고일, 공개데이터 확인일, 출처 및 주의 문구 표시
- 첫 검수 제품: `조선미녀 맑은 쌀 선크림` ↔ `조선미녀맑은쌀선크림`
- 리뷰점수, 맞춤점수, 광고점수 계산에는 영향을 주지 않음

### 2.2 2차 부분 구현 현황

2026-09-04 기준으로 식약처 사용제한 원료를 화력 성분에 검수 연결하고 공개하는 흐름을 적용했다.

- 관리자 원천 데이터 화면에서 화력 성분별 식약처 후보 검색
- 표준명·영문명 일치율, CAS No, 국가, 제한 유형, 고시 원료명, 조건·단서 원문 비교
- 관리자 확인 연결·해제와 검수자·검수일·검수 메모 기록
- 관리자 연결이 끝난 정보만 성분 상세의 `공식 사용조건 참고`에 공개
- 제품 성분 배지는 브랜드 공식 전성분이 검증·공개된 제품에만 표시
- 첫 검수 성분: `판테놀` ↔ 일본 `Panthenol` 한도 레코드
- 성분의 `GOOD`, `CAUTION`, `NEUTRAL` 상태와 사용자 리뷰점수에는 영향을 주지 않음

식약처 매칭 여부 때문에 제품 리뷰점수가 오르거나 광고 노출 순서가 자동으로 올라가면 안 된다.

### 3.2 표현 원칙

- 기능성화장품 데이터는 `식약처 보고정보 확인`으로 표시한다.
- `식약처 인증`, `식약처가 추천한 제품`, `안전이 보장된 제품`이라고 표현하지 않는다.
- 사용제한 원료정보는 국가, 제한 유형, 사용 부위, 농도, 예외 조건을 함께 보여준다.
- 특정 원료 레코드가 있다는 이유만으로 `위험 성분` 또는 `사용 금지 제품`이라고 단정하지 않는다.
- 제품의 실제 함유 여부는 브랜드 공식 전성분이 확보되고 표준 성분명과 매칭된 경우에만 표시한다.
- 모든 공개 정보에는 출처와 마지막 확인일을 표시한다.

## 5. P0 기능 상세

### 5.1 관리자용 식약처 제품 매칭

#### 화면 위치

`관리자 > 상품 관리 > 상품 상세 > 식약처 보고정보`

#### 화면 구성

- 현재 연결 상태: `미연결`, `자동 추천`, `관리자 확인`, `연결 제외`
- 식약처 품목명 검색창
- 검색 결과에 품목명, 업체명, 보고일, 제조/수입 구분을 표시
- 화력 제품과 식약처 후보를 좌우로 비교
- `이 제품과 연결`, `다른 후보 찾기`, `해당 없음` 버튼
- 매칭 방법, 검수자, 검수일, 검수 메모 기록

#### 후보 추천 규칙

완전 일치만 사용하지 않고 다음 순서로 후보를 만든다.

1. 제품명에서 용량, 괄호, 기획세트, 증정, 리뉴얼 문구를 제거한다.
2. 한글·영문 공백과 특수문자를 정규화한다.
3. 화력 브랜드명과 식약처 업체명을 별도 비교한다.
4. 제품명 토큰 유사도와 업체명 유사도를 조합한다.
5. 보고 취소 여부와 보고일을 확인한다.
6. 상위 5개 후보만 관리자에게 제시한다.

자동 후보는 공개 근거로 바로 사용하지 않는다. 관리자 확인이 끝난 `ADMIN_VERIFIED` 연결만 사용자 화면에 노출한다.

#### 매칭 점수 예시

```text
후보 신뢰도
= 제품명 유사도 65%
+ 업체/브랜드 유사도 25%
+ 카테고리·기능성 단서 10%
```

- 90점 이상: 강한 후보, 관리자 확인 필요
- 70~89점: 일반 후보
- 70점 미만: 기본 목록에서 숨기고 직접 검색으로만 확인

### 5.2 제품 상세의 식약처 보고정보 카드

#### 노출 조건

- 상품이 공개 상태다.
- 관리자 검수가 완료된 식약처 품목 연결이 있다.
- 연결된 원문 데이터가 최신 동기화에도 존재한다.

#### 위치

제품명·가격 아래 또는 `화력 리포트`의 데이터 신뢰 영역에 작은 배지로 먼저 표시하고, 누르면 상세 카드로 이동한다.

#### 표시 정보

```text
[식약처 보고정보 확인]

기능성화장품 보고품목에서 확인된 제품이에요.
품목명       ○○ 선크림
책임판매업체  ○○코스메틱
보고일       2025.03.18
기능성 구분   자외선 차단

2026.09.04 식약처 공개데이터 확인
[원문 정보 보기]
```

하단 안내문:

> 이 표시는 식약처 공개 보고정보와 제품을 연결했다는 뜻이며, 제품의 효능이나 개인별 안전성을 보장하지 않습니다.

### 5.3 사용제한 원료정보 연결

사용제한 원료 31,122건을 그대로 사용자에게 나열하지 않는다. 브랜드 공식 전성분과 연결된 정보만 제품 상세에 보여준다.

#### 처리 흐름

```text
브랜드 공식 전성분
→ 대한화장품협회 표준명·영문명·CAS 번호 매칭
→ 식약처 사용제한 원료 후보 조회
→ 국가·제한 유형·조건 정규화
→ 관리자 검수
→ 제품 상세 공개
```

#### 제품 상세 UI

성분 행에 `사용 조건 확인` 배지를 표시한다. 배지를 누르면 다음 내용을 보여준다.

- 표준 성분명과 영문명
- 적용 국가 또는 기준 출처
- 제한 유형
- 허용 농도·사용 부위 등 제한 조건
- 예외·단서 조항
- 식약처 원문 출처와 확인일
- `이 정보만으로 제품의 적합성이나 위험을 단정할 수 없음` 안내

국내 기준과 해외 참고 레코드는 탭이나 라벨로 명확히 분리한다.

### 5.4 데이터 신뢰도 반영

현재 맞춤점수의 데이터 신뢰 영역은 전체 점수의 10%다. 식약처 연결은 이 영역의 근거로만 사용한다.

권장 데이터 신뢰도 내부 구성:

| 항목 | 비중 |
| --- | ---: |
| 브랜드 공식 전성분 확보 | 45 |
| 표준 성분 매칭 완성도 | 25 |
| 식약처 품목 관리자 검수 연결 | 15 |
| 출처 확인일 최신성 | 10 |
| 관리자 최종 검수 | 5 |

식약처 품목 연결만 있고 공식 전성분이 없다면 높은 데이터 신뢰 등급을 부여하지 않는다. 기능성 보고정보는 전성분을 대신할 수 없기 때문이다.

## 6. P1 기능 상세

### 6.1 제품 검색과 필터

제품 목록에 다음 필터를 추가한다.

- `식약처 보고정보 확인`
- 기능성 유형: 자외선 차단, 피부톤, 주름 등
- 데이터 근거: 공식 전성분 확인, 식약처 정보 확인
- 정보 확인일

필터 결과가 적을 때는 식약처에만 존재하는 미등록 상품을 섞지 않는다. 화력에서 검수하고 공개한 제품만 검색 결과에 노출한다.

### 6.2 식약처 품목에서 신규 상품 초안 생성

관리자 화면에서 식약처 품목을 검색한 뒤 `화력 상품 초안 만들기`를 제공한다.

자동 입력 가능 항목:

- 제품명
- 업체명 또는 브랜드 후보
- 기능성 구분
- 보고일
- 식약처 원문 식별자

자동 입력하면 안 되는 항목:

- 사용자 리뷰점수
- 화력 성분점수
- 판매 가격
- 대표 이미지
- 쿠팡 파트너스 링크
- 브랜드 공식 전성분

초안은 `DRAFT`로만 만들고, 이미지·공식 전성분·쿠팡 공식판매처 링크·출처 확인 후 공개한다.

### 6.3 성분 사전의 규제 참고 영역

성분 상세 페이지에 `공식 사용조건 참고` 영역을 추가한다.

- 한글 표준명, 영문명, CAS 번호로 레코드 연결
- 국가별 레코드 묶음 표시
- 금지, 한도, 사용 부위, 기타 조건으로 분류
- 같은 내용의 중복 레코드는 하나로 묶기
- 원문과 마지막 동기화 일시 표시

`GOOD`, `CAUTION`, `NEUTRAL` 상태를 식약처 레코드만으로 자동 변경하지 않는다. 상태 변경은 근거 검토와 관리자 승인을 거친다.

### 6.4 랭킹과 화력 리포트

- 랭킹 카드의 `성분 근거 높음/보통/자료 보강 중` 계산에 검수된 식약처 연결을 사용한다.
- 추천 이유에는 `식약처 보고정보와 브랜드 공식 전성분을 확인했어요`처럼 출처 근거만 표시한다.
- 사용자 리뷰점수, 리뷰 랭킹, 사용자 평균 점수에는 반영하지 않는다.
- 광고 탭의 관리자 추천점수에도 자동 가산하지 않는다. 단, 공개 전 `근거 완성도` 검수 조건으로 활용할 수 있다.

## 7. P2 운영 기능

### 7.1 변경 감지

동기화 때 원문 해시를 비교해 다음 변경을 별도 저장한다.

- 신규 품목
- 품목명 또는 업체명 변경
- 보고 취소 상태 변경
- 기능성 정보 변경
- 사용제한 조건 변경
- 기존 레코드 누락

관리자 홈에는 `확인 필요한 변경` 카드로 표시하고, 화력 상품과 연결된 레코드를 최우선으로 보여준다.

### 7.2 정기 동기화

- 기본 주기: 하루 1회 새벽 동기화
- 실패 시 자동 재시도: 최대 3회
- 같은 원문은 다시 저장하지 않고 확인일만 갱신
- 연결된 제품에 영향을 주는 변경은 관리자 검수 큐 생성
- 연속 실패, 전체 건수 급감, 중복률 급증 시 관리자 경고

## 13. 바로 다음 작업

`관리자 상품별 식약처 품목 매칭 화면`, 사용자 제품 상세의 검수 정보, 성분별 사용조건 후보 검수와 성분 상세 공개까지 구현했다. 제품 상세의 사용조건 배지는 브랜드 공식 전성분이 검증된 경우에만 나타나며, 현재 공식 전성분 등록 제품이 없어 제품 함유정보처럼 노출되는 항목은 없다.

다음 작업은 사용권이 확인된 대한화장품협회 성분 파일과 브랜드 공식 전성분을 적재하는 것이다. 그 뒤 CAS 별칭 매칭과 국가·제한 유형 정규화를 보강하고, 나머지 공개 상품을 `연결 확인` 또는 `해당 없음 확인` 상태로 정리한다.
