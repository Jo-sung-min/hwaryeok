# 메인 상품 진열 개편

## 화면 순서

1. 이미지 중심 배너: PC에서는 카드 3개, 태블릿 2개, 모바일 1개. 실제 공개 제품 이미지로 최대 10개를 구성하고 5초 간격으로 순환한다. 이전/다음·재생/정지 및 동작 줄이기 설정을 지원한다.
2. ‘나의 성분 찾기’ 버튼: 피부 조사로 연결한다. 직접 성분을 선택하는 기존 랭킹 진입점도 유지한다.
3. 전체 상품/맞춤 상품: 비로그인은 제품명순 전체 상품. 로그인했지만 조사 미완료이면 전체 상품과 조사 안내. 로그인하고 조사 결과가 저장된 경우에만 내 피부 화력순으로 자동 전환한다.
4. 내 피부에 맞는 제품 랭킹: 저장된 조사 결과로 계산한 상위 4개와 전체보기. 미조사·비로그인에게 임의 피부타입의 순위를 표시하지 않는다.
5. 급상승 랭킹: 실제 공개 리뷰 증가량 상위 4개와 전체보기. 집계할 리뷰가 없으면 빈 상태와 리뷰 참여 안내를 제공한다.

메인 카테고리 탭은 메인 페이지 안에서 상품·맞춤 랭킹·급상승 랭킹에 함께 적용된다. 카테고리 변경은 첫 페이지부터 조회하고, 별도 전체보기 화면은 해당 카테고리를 유지한다.

## 동작과 데이터

- 기본 상품은 공개 제품 전체가 대상이다. 성분 연결이 없는 제품을 전체 상품에서 임의로 제외하지 않는다.
- 맞춤 순서는 기존 성분/피부 적합도 엔진의 점수, 성분 점수, 근거 수준, 제품 ID 순으로 정렬한다. 제품 리뷰점수 및 광고 점수와 혼합하지 않는다.
- 급상승은 `최근 7일 리뷰 수 - 이전 7일 리뷰 수`가 양수인 제품만 표시한다. 순위 상승 칸 수나 판매량으로 표현하지 않는다.
- 급상승 동률은 최근 리뷰 수, 최근 리뷰 평균, 제품 ID로 정렬한다. 비공개 제품과 비활성 사용자의 리뷰는 제외한다.
- 피부 조사 내용은 서버에서만 읽으며 공개 주소에 노출하지 않는다.
- `/ranking/personal`: 내 피부에 맞는 제품 전체보기. `/ranking/rising`: 급상승 전체보기. 카테고리와 페이지 이동 지원.
- 기존 `/?ingredient=...` 또는 리뷰점수순 링크는 `/ranking` 성분 탐색기로 연결하여 유지한다. `/?category=...`는 새로운 메인 카테고리 필터다.
- 배너는 기존 확인된 성분 가이드와 공개 제품 이미지를 활용한다. 이번 범위는 최대 10장 순환 UI이며 별도의 배너 업로드·편성 관리자 도구는 추가하지 않는다.

## 검증 기준

배너 0~10개, 중복/이미지 누락/비공개 제외, 끝에서 처음으로 순환, 모바일 및 키보드 동작을 확인한다. 게스트·로그인 미조사·로그인 조사완료 모드, 카테고리 유지, 실제 맞춤 점수 정렬, 급상승의 날짜 경계·비공개/비활성 제외를 검증한다. 실제 서비스에 검증용 리뷰를 만들지 않는다.

## 확인 결과 (2026-09-07)

- 백엔드 전체 테스트 145개(급상승 신규 8개 포함) 통과. 프론트 홈 상태/배너 데이터 테스트 4개, 타입 검사, 배포 빌드 통과.
- 실제 PostgreSQL 백엔드 재시작 후 신규 API와 메인·개인 랭킹·급상승 페이지 정상 응답 확인.
- 동일한 가상 피부 조건으로 상품 목록과 랭킹 API의 점수·순서 일치 확인. 피부 조건은 저장하지 않고 조회만 수행했다.
- 브라우저에서 데스크톱 3장, 10→1 순환, 자동 이동, 카테고리 변경 후 앰플 3개 표시, 급상승 전체보기에서 카테고리 유지 확인.
- 390px 모바일에서 가로 넘침 없음, 단일 배너·성분 찾기 버튼·2열 상품 진열 확인. 실제 회원 계정으로 새 피부 조사나 리뷰를 등록하는 테스트는 하지 않았다.
