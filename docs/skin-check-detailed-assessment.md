# 피부 상태 자가 체크 개선

> 결과 화면은 이후 [읽기 중심 상세 리포트](./skin-check-result-report.md)로 개선했다. 아래 내용은 15문항 설문의 최초 구현 기록이며 결과의 카드 수정·프로필 저장 연결·새로고침 복원 방식은 새 문서를 기준으로 한다.

## 목표

피부 타입 이름을 사용자가 먼저 선택하는 방식에서 벗어나, 실제로 느낀 피부 상태를 묻고 답변 기반 경향과 추천 기준을 보여준다. 도중·완료 후 모두 원하는 문항만 수정할 수 있다.

## 구현한 문항

총 15문항. 기본 선택값은 두지 않는다.

| 영역 | 문항 |
| --- | --- |
| 유수분 관찰 | 오후 이마·코 유분, 같은 시간 볼의 상태, 속당김, 세안 후 당김 |
| 피부 반응 | 제품 사용 시 민감 반응, 붉어짐, 최근 한 달 트러블, 모공 체감 |
| 우선순위 | 고민 1~3개, 선호 마무리감, 루틴 단계 |
| 생활·환경 | 선케어 습관, 불편했던 성분, 반복 관리 습관, 생활환경 |

마지막 세 문항은 선택 사항. ‘아직 모름’은 특정 성분 선택과 함께 선택되지 않는다. 다중 선택 상한, 필수 답변, 서버에 전달하는 프로필의 자료형·열거값을 검증한다.

## 화면과 이동

- 흰 배경, 분홍 선택 표시, 영역별 은은한 색상과 아이콘. 그라데이션 없음.
- 한 번에 한 질문. 단일 선택은 설명이 있는 가로 카드, 복수 선택은 2열 카드.
- 짧은 화면에서는 복수 선택 카드의 장식 아이콘을 줄이고 설명은 유지한다. 콘텐츠만 내부 스크롤되며 다음·이전 버튼은 항상 보인다.
- 첫 문항은 이전 버튼을 생성하지 않아 다음 버튼이 중앙 전체 너비에 놓인다.
- 상단 ‘답변 보기’에서 15문항을 확인하고 항목별 수정. ‘수정 완료’는 답변 노트로 복귀.
- 결과에서 ‘답변 수정’ 또는 상태 카드를 눌러 수정 후 재계산. 다른 답변은 유지하고 이전 제품 결과는 무효화한다.
- 브라우저 뒤로/앞으로 이동 지원. URL에는 단계만 기록하고 피부 답변은 넣지 않는다.
- 이 탭의 sessionStorage에 마지막 변경 기준 24시간 유효한 초안을 보관. 새로고침 시 복원하며 오래되거나 손상된 값은 버린다. 추천 결과 자체는 복원하지 않고 답변 확인 화면으로 돌아온다.
- 프로필 저장 이동을 직접 누를 때만 기존 localStorage 전달 형식으로 저장한다. 계정 프로필 저장은 기존 상세 프로필의 확인·저장 절차를 거친다.

## 결과 해석 및 기존 추천 연동

유분의 부위 차이와 속당김으로 건성·지성·복합성·수부지·중성 **경향**을 표시한다. 민감 반응은 별도 표시한다. 이는 화력의 제품 선택용 규칙이며 임상 검증된 진단 알고리즘이 아니다. 정확도 백분율, 기기 측정값, 확정 진단 표현은 사용하지 않는다.

일반적인 건조함·유분·부위 차이·제품 사용 후 민감 반응이라는 관찰 용어는 [미국피부과학회 피부 관리 안내](https://www.aad.org/public/everyday-care/skin-care-basics/care/skin-care-for-men)를 참고했다. 이 자료가 화력의 설문이나 분류 규칙을 검증·보증한다는 의미는 아니다.

결과 상단에 분류에 쓰인 세 답변과 세안 후 당김·민감 반응·붉어짐·트러블을 보여준다. 실제 측정이나 의료 진단이 아님을 안내한다.

기존 getRanking API에 실제 답변을 전달한다. 세안 후 당김·붉어짐·모공 상태를 다른 답변으로 자동 생성하던 방식은 제거했다. 볼의 유분은 프런트 분류에 사용하고 기존 skinType으로 전달한다. 별도 DB 스키마 변경은 없다. 제품 추천 실패 시에도 피부 요약과 답변 수정은 유지하며 재시도가 가능하다. 제품 추천 점수와 피부 측정값을 구분한다.

## 검증

- 새 설문 로직 테스트 8개: 미응답, 선택 제한, 독립 답변 수정, 피부 경향 규칙, 실제 답변 보존, 초안 만료·손상, 요청 값 검증.
- 기존 테스트 포함 26개 통과. 타입 검사와 Next 프로덕션 빌드 통과.
- 브라우저: 15문항 진행, 이전 답변 유지, 브라우저 뒤로가기, 새로고침 복원, 최대 3개 고민 선택, ‘아직 모름’ 배타 선택, 선택 문항 건너뛰기 확인.
- 390×844 및 320×568에서 선택지·하단 버튼 확인. 가장 많은 8개 선택지도 작은 화면에서 버튼 영역 위에 배치되며 부가 안내는 내부 스크롤로 읽을 수 있다.
- 실제 로컬 추천 API에서 제품 3개 표시 확인. 계정 저장·리뷰 생성 등 사용자 데이터 변경은 하지 않음.
- 결과의 1번 답변을 변경한 뒤 복합성 → 건성 경향으로 재계산되고 추천 제품 구성이 바뀌는 것 확인. 2번 등 다른 답변은 그대로 유지.

## 범위 밖

사진 분석, 센서 측정, 임상 정확도 검증, 과거 체크 결과의 계정별 이력은 이번 구현에 포함하지 않는다. 이번 변경은 자기 보고형 피부 상태 체크와 기존 추천 연결이다.
