# 화력 메인: 배너와 카테고리별 상품 진열

작성일: 2026-09-07

## 이번 변경

[화해 홈](https://www.hwahae.co.kr/)의 배너, 주제별 상품 묶음, 각 묶음의 전체보기 흐름을 참고한다. 화면 구성만 참고하며 화력의 흰색·연분홍색과 성분 중심 탐색을 유지한다. 화해의 리뷰·순위·광고 문구를 화력 데이터로 복제하지 않는다.

메인은 여러 카테고리를 둘러보는 진열 화면, `/ranking`은 조건에 맞는 전체 제품을 정렬·페이지 이동하며 비교하는 화면으로 역할을 나눈다.

## 화면 순서

1. 제품명·브랜드 검색
2. 성분과 제품 종류로 바로 연결되는 배너: 히알루론산 × 앰플, 판테놀 × 크림, 어성초 × 토너
3. 앰플·세럼·크림·토너 등 제품 카테고리 바로가기
4. 관심 성분 선택 및 전체 성분 검색
5. 카테고리별 상품 진열과 각각의 전체보기
6. 별도 광고 추천 탭 안내 및 점수 집계 기준

배너는 해당 성분·카테고리에 실제 공개 제품과 이미지가 있을 때만 만든다. 자동 전환 없이 이전/다음 버튼으로 이동한다. 모든 배너를 만들 수 없는 경우 피부 체크 안내를 보여준다.

모바일 상품 구역은 가로 넘김으로 다음 제품을 발견할 수 있게 하고, 데스크톱에서는 최대 4개를 한 줄에 표시한다. 상품 이미지가 잘리지 않도록 여백과 비율을 고정한다. 제품 종류별로 최대 4개만 미리 보여주고, 전체보기에서 나머지 제품을 조회한다.

## 동작과 데이터 기준

- 메인의 성분 선택은 모든 카테고리 구역에 적용된다. 예를 들어 히알루론산을 고르면 히알루론산 앰플·세럼·크림·토너·에센스 구역만 나타난다.
- 각 구역의 상단 링크와 하단 버튼은 같은 성분·카테고리 조건의 `/ranking`으로 연결된다.
- 카테고리 바로가기는 현재 메인 안의 해당 구역으로 이동하며, 전체보기는 선택 성분의 전체 랭킹을 연다.
- 기존 `/?ingredient=...&category=...`, `/?sort=REVIEW`, `/?page=2` 링크는 조건을 보존하여 `/ranking`으로 이동한다.
- 제품·개수·가격·리뷰·성분점수는 기존 API 결과를 사용한다. 성분 미선택 상태의 기본 점수를 사용자 리뷰나 성분 순위로 표시하지 않는다.
- 성분 선택 시에만 해당 성분의 비교점수와 순위를 표시한다. 리뷰 없는 제품은 ‘첫 리뷰를 기다려요’로 안내한다.
- 광고 관리자 점수는 일반 상품 구역에 합산하지 않는다. 이번 작업 시 광고 등록은 0개이므로 가짜 광고 상품 대신 광고 탭 안내만 노출한다.
- 찜·제품 상세·검색·저장된 관심 성분 우선 표시 기능은 유지한다.

## 운영 및 확장

현재 공개 제품 22개와 9개 카테고리를 사용한다. 성분이 연결된 제품만 성분 필터에 포함하며, 추가 제품이 공개되면 카테고리와 전체 수가 자동 갱신된다.

조회는 기존 API를 병렬 사용한다. 제품 수가 크게 늘어나면 카테고리별 상위 제품을 한 번에 반환하는 홈 전용 조회와 배너 캐싱을 후속 최적화 대상으로 둔다. 현재 구조에서도 표시 개수는 카테고리당 4개로 제한한다.
