# 피부 체크 한 화면 선택 UI

> 초기 7문항 UI 변경 기록입니다. 이후 적용된 15문항 설문·답변 수정·결과 화면은 [상세 개선 문서](./skin-check-detailed-assessment.md)를 기준으로 확인하세요.

2026-09-10 적용. 기존 594px 앱 폭과 다른 페이지 구성은 유지한다.

- 질문 응답 중에만 공통 헤더·푸터·하단 메뉴를 숨기고 홈 복귀, 단계 표시를 제공한다.
- 동적 화면 높이(100dvh)에 맞춰 질문 영역과 하단 이전·다음 버튼을 배치한다.
- 기본 선택지는 2열, 민감도·트러블 및 제형·루틴의 각 그룹은 3열로 배치한다.
- 기존 마지막 단계의 반응 성분과 생활 습관을 분리하여 총 7단계로 구성한다. 수집 항목과 추천 요청 형식은 바꾸지 않는다.
- 다음 단계 이동 시 질문 제목으로 키보드 초점을 옮기고 질문 영역 스크롤을 초기화한다.
- 짧은 가로 화면이나 글자 확대에서는 질문 영역 내부 스크롤을 허용한다. 선택 내용을 잘라내거나 전체 화면 스크롤을 강제로 잠그지 않는다.
- 결과 화면으로 바뀌거나 다른 페이지로 이동하면 공통 메뉴가 복원된다.

## 검증

- 320×568에서 7개 단계 모두 질문 영역 scrollHeight = clientHeight, 하단 행동 버튼 화면 내부 위치 확인
- 390×844에서 선택 표시 확인
- 568×320에서 질문 영역 내부 스크롤과 하단 버튼 가시성 확인
- 기본 PC 화면에서 한 화면 표시 확인
- ‘아직 모름’과 구체적 반응 성분의 배타 선택 유지
- 피부 고민 0개일 때 다음 버튼 비활성화 확인
- 홈 복귀 시 상단·하단 메뉴 복원 및 브라우저 오류 없음
- 전체 프런트엔드 빌드·타입 검사 통과

화면 검증용 선택은 저장하거나 추천 계산을 제출하지 않았다. 실제 사용자 프로필과 백엔드 설정은 변경하지 않았다.
